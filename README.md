# Student Goal Tracking System

## 📌 About the Project

Student Goal Tracking System is a Python and SQLite-based application that helps students create, manage, and track their academic and personal goals.

## 🚀 Features

* Student Registration
* Student Login
* Add Goals
* View Goals
* Update Goal Progress
* Delete Goals
* Dashboard
* Automatic Completed/Pending Status
* Logout and Exit

## 🛠️ Technologies Used

* Python
* SQL
* SQLite
* Google Colab

## 🗄️ Database

The project contains two tables:

* **Students** – stores student details and login information.
* **Goals** – stores goal details, target dates, progress, and status.

## 📊 Dashboard

The dashboard displays:

* Total Goals
* Completed Goals
* Pending Goals
* Average Progress

## ▶️ How to Run

1. Open the project in Google Colab.
2. Run the code cells in order.
3. Run the `main()` function.
4. Register as a student.
5. Login using your email and password.
6. Add and manage your goals.
